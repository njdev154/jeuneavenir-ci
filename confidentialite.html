INFORMATIONS V1

Confidentialité et données locales.

Dernière mise à jour : 25 novembre 2026. Cette page distingue le pilote statique du mode de développement Laravel local; elle ne promet ni ouverture publique ni durée légale de conservation.

DANS TON NAVIGATEUR

Ce que l’application enregistre localement

Les données ci-dessous sont écrites dans le localStorage par les fonctionnalités concernées. Elles restent dans le profil du navigateur et de l’appareil utilisés; elles ne sont pas synchronisées avec un compte en ligne.

Profil et session

Les comptes et profils ne sont pas activés pendant le pilote. D’anciennes clés locales (jac_utilisateurs, jac_utilisateur_connecte) peuvent subsister sur un appareil ayant déjà servi aux essais; le pilote ne les lit pas.

Orientation et favoris

Dans le pilote statique, jac_orientation_parcours_v1 conserve localement le profil facultatif, les réponses, la progression et le texte facultatif du quiz; jac_dernier_resultat_quiz conserve le résultat et les réponses; jac_favoris conserve les éléments mis de côté. Dans le mode Laravel local, les réponses sont envoyées à l’API du même site uniquement pour le calcul, sans enregistrement par l’application côté serveur; le résultat et ses réponses restent temporairement dans sessionStorage jusqu’à la fermeture de l’onglet. jac_orientation_api_resultat_session identifie cette donnée temporaire. Aucun de ces parcours n’est relié au compte Jeune.

Démarches et offres locales

Les candidatures, demandes de mentorat et publications d’offres sont désactivées. D’anciennes données de démonstration (jac_candidatures, jac_demandes_mentorat, jac_offres_entreprise) peuvent rester sur un appareil utilisé pour des essais; le pilote ne les lit pas.

Avis sur l’interface

Le formulaire Avis est désactivé et ne collecte aucun retour. Une ancienne clé jac_avis peut subsister depuis les essais précédents; le pilote ne la lit pas.

FORMULAIRES

Contact et anciennes données locales

Dans le pilote statique, les formulaires Contact, Avis, compte, candidature, mentorat et publication sont désactivés. Le quiz API est disponible seulement si le site est servi par Laravel en local; l’inscription Jeune exige en plus l’activation explicite du compte de développement. N’utilise que des données fictives et ne saisis aucune coordonnée personnelle.

Le bouton « Effacer les données de cet appareil » supprime les clés JeuneAvenir commençant par jac_ dans le stockage local et dans l’onglet, y compris le résultat temporaire du quiz API. La suppression nécessite une confirmation; elle ne supprime pas d’éventuels journaux techniques du serveur.

CHARGEMENT DU SITE

Requêtes réseau et services tiers

Fichiers du site

Les catalogues sont chargés depuis les fichiers du site. Dans le pilote statique, le quiz calcule dans le navigateur. Sur Laravel local, il charge sept questions depuis l’API et lui transmet uniquement la série choisie, les identifiants des questions et les indices de réponse pour calculer des pistes; le profil facultatif et le texte libre ne sont pas envoyés. L’API ne stocke pas les réponses et ne les transmet pas à un service externe. Le résultat contenant les réponses est gardé dans sessionStorage jusqu’à la fermeture de l’onglet. L’hébergeur reçoit nécessairement les requêtes techniques et pourrait appliquer ses propres journaux; aucune conservation d’hébergement n’est déterminée ici.

Polices et liens externes

Les pages chargent Instrument Serif et Manrope depuis Google Fonts. Cette requête contacte l’infrastructure de Google Fonts; consulte les informations de confidentialité de Google pour ses traitements. Des liens vers des sources externes peuvent également être ouverts par choix de l’utilisateur. Aucun outil d’analytique ou de publicité tiers n’a été identifié dans les scripts applicatifs examinés.

TES CHOIX

Conservation et suppression

Dans le pilote statique, le quiz et les favoris sont conservés dans le navigateur. Dans le mode Laravel local, les réponses transitent vers l’API sans être stockées par celle-ci et le résultat reste temporairement dans l’onglet. Aucun résultat n’est synchronisé avec le compte. Le bouton d’effacement retire les clés JeuneAvenir des stockages de cet appareil; il ne peut pas effacer les journaux éventuels de l’hébergeur.

Ne saisis pas de coordonnées, de mot de passe, de document d’identité ni d’information sensible. Si tu utilises un appareil partagé, efface les données JeuneAvenir avant de le quitter.

À L’AVENIR

Les évolutions envisagées ne sont pas actives

Une première API d’orientation et une première session de compte existent uniquement pour les essais locaux, désactivées par défaut et non prêtes pour le public. Toute mise en service devra préciser les données concernées, les responsabilités, les durées et les moyens de contrôle avant d’être présentée comme opérationnelle.

Pour les fonctionnalités et leurs limites actuelles, consulte aussi la FAQ. Le formulaire Contact est désactivé pendant ce pilote.
