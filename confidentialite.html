Politique de confidentialité

Dernière mise à jour : 20 août 2026 — version de lancement (V1)

Ce que fait vraiment le site aujourd'hui

JeuneAvenir CI est actuellement dans sa version de lancement. Toutes les informations que tu saisis (compte, profil, favoris, candidatures, demandes de mentorat, messages) sont enregistrées uniquement dans ton navigateur (technique appelée "localStorage"), sur l'appareil que tu utilises. Rien n'est envoyé sur un serveur externe pour l'instant.

Ce que ça veut dire concrètement

Si tu changes de téléphone, d'ordinateur, ou si tu vides le cache de ton navigateur, ces informations seront perdues. Ce n'est pas un manque de sérieux : c'est une étape de développement, avant la mise en place d'une vraie base de données sécurisée.

Prochaine version

Une prochaine version du site utilisera une vraie authentification sécurisée et une base de données, avec une politique de confidentialité complète décrivant précisément quelles données sont conservées, pour combien de temps, et comment les supprimer.
